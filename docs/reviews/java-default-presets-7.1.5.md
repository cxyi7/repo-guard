## 接入与校验边界

createProjectDocument 返回新建模板，Java 模板在生成已有规则和阈值后写入启用意图。未准备的 command、modules、pluginVersion、Enforcer 执行标识保持真实空值，不填写假工具、假模块或假报告。

模板尚未补齐时不满足严格运行配置 Schema。init 写入后继续执行真实配置校验，明确报错并保留配置，校验通过前不安装 Hook；再次 init 不覆盖文件。人或后续 Skill 补齐后再次 init。没有新增宽松 Schema、旧格式兼容入口或绕过配置校验的运行路径。

已有配置的显式关闭值、省略值、用户阈值保持不变。检查命令不安装依赖、不改写项目工具配置。没有更改 Java 规则、工具适配器或证据标准。
