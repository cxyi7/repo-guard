# 表单标签与图片替代文本删除审查（6.0.0）

## 范围与版本

用户明确要求删除两个门禁，不保留兼容入口。公开命令、CI Gate ID、固定生命周期步骤和托管规范被删除，属于不兼容变更，目标版本为 6.0.0，未发布。

基于现有源码安全工作树创建独立分支，保留此前修改。消费项目升级要求见[删除说明](../features/template-accessibility-removal.md)。

## 删除与审查

- 删除两个策略实现、可访问性 Gate 模块、仅供其使用的 Vue 策略适配器，以及模板元素树扫描函数和专用常量。
- 删除专用测试文件；更新完整执行计划、能力登记、CI 报告、初始化和 Doctor 预期。
- 回归断言旧命令返回统一错误码，旧 CI ID 被拒绝；没有别名、重定向或静默忽略。
- 使用缺少标签和 alt 的真实暂存 Vue 文件验证前后端应用不再因这两项阻断。
- 托管 AI 规范不再生成相应要求；Schema 删除旧规则示例，未引入新的配置项。
- 保留图片引用与异步资源清理使用的共享解析逻辑，以及源码安全使用的编译器与 Babel；没有独占 npm 依赖可删除。
- 全文检索确认运行时代码无旧命令、规则和 Gate 引用；文档中的旧标识仅用于删除说明，测试仅用于拒绝或缺失断言。

## 实际遇到的问题

1. 默认 npm 缓存位于受限目录，首次打包检查出现 EPERM。将缓存设为仓库 test/.tmp/npm-pack-cache 后成功，不修改包行为。
2. 删除模板树扫描函数后，ESLint 检出未使用的 VOID_ELEMENTS 常量。删除常量后完整工程检查通过。
3. 测试运行期间一次写入测试文件遇到 Windows UNKNOWN 文件访问错误；重新读取确认内容，重试成功，后续针对性回归通过。

4. 完整回归发现两条旧 pre-commit 测试仍断言缺少标签或 alt 返回违规码，实际返回成功，符合删除后的要求。将预期改为放行并保留暂存内容断言，两项真实 Hook 复跑均通过；没有修改运行时代码来迁就旧预期。
