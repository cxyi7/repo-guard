31 项可配置功能，一张表看清楚

repo-guard · 配置 v2

同一套团队规范，分别应用于前端和 Node 后端。Vue 专用检查仅适用于前端。

功能名配置位置功能说明初始状态自动入口 / 触发方式
eslintchecks.eslint检查 JS、TS、Vue 代码问题，并按项目规则修复可修复项开提交、CI full/release-ready
prettierchecks.prettier统一缩进、换行、引号等代码与文档格式开提交、CI full/release-ready
stylelintchecks.stylelint检查 CSS、预处理样式与 Vue 样式规范关提交、CI full/release-ready
styleComplexitychecks.styleComplexity限制选择器组合数量和样式嵌套深度关随 Stylelint
styleGovernancechecks.styleGovernance约束样式优先级、ID、!important 和全局样式位置关随 Stylelint
fileHeaderchecks.fileHeader按 Git 事实同步文件头信息，保留人工描述关提交
functionDocschecks.functionDocs随函数签名同步文档标签，保留业务说明关提交
asyncResourceCleanupchecks.asyncResourceCleanup检查 Vue 组件与组合函数的定时器、监听等资源清理关提交、CI 三档
pathNamingchecks.pathNaming统一文件与目录的 camelCase 或 kebab-case 命名关提交、CI 三档
uiTokenschecks.uiTokens要求受控颜色、间距、字号等使用项目声明的设计 Token关提交、CI 三档
filePlacementchecks.filePlacement按文件类型限制存放目录，避免资源和文档散落开提交、CI 三档
maxFileLineschecks.maxFileLines限制单文件规模，提示接近上限或阻断继续膨胀开提交、CI 三档
codePlacementrepository.codePlacement限制指定代码文本只在允许的文件中出现关提交、CI 三档
dependenciesrepository.dependencyPolicy检查依赖版本、来源、重复声明和锁文件一致性开提交、CI 三档
commitMessagerepository.commitMessage统一提交信息格式，并在推送和 CI 复核提交历史关提交信息、推送、CI 三档
imageAssetschecks.imageAssets检查图片命名、真实格式、重复内容及优化收益关提交、CI 三档
unusedImageAssetschecks.unusedImageAssets查找没有有效引用的图片，支持限制新增历史债务关推送、CI full/release-ready
deliveryContractrepository.deliveryContract把需求、任务、测试、人工验收与反馈绑定为可复核交付关提交、CI 三档
typeCheckchecks.typeCheck调用项目类型脚本，检查 TypeScript 或 Vue 类型错误关推送、CI full/release-ready
architecturechecks.architecture检查循环依赖、导入解析与团队模块分层边界关推送、CI full/release-ready
deadCodechecks.deadCode使用 Knip 检查无效文件、导出和依赖，支持历史基线关推送、CI full/release-ready
buildchecks.build执行项目构建，并检查已配置的产物预算关推送、CI full/release-ready
lighthousechecks.lighthouse检查 Vue 页面的性能等 Lighthouse 指标和项目断言关推送、release-ready
unitTestchecks.unitTest执行项目 Vitest，并检查源码与测试的对应关系关推送、CI full/release-ready；policy 检查资料
componentInteractionchecks.componentInteraction要求 Vue 组件测试包含真实操作及可观察结果断言关随单元测试及资料策略
coveragechecks.coverage检查测试覆盖率与本次变更行覆盖率是否达标关随完整单元测试执行
accessibilityTestchecks.accessibilityTest执行项目 axe 测试，检查实际界面的可访问性问题关推送、CI full/release-ready
mutationTestchecks.mutationTest用 Stryker 改动代码验证测试能否发现错误关显式手动或受保护构建
notificationreporting.notification在适用的本地保护文件和构建失败流程发送企业微信通知开适用的本地通知流程
commitAnimationreporting.commitAnimation用小猫或小狗展示提交检查状态，真实提交成功后播放类型道具和彩蛋关本地 pre-commit / post-commit
cici在 CI 按固定配置档复核规则并输出统一报告关显式 CI / 托管 Job
